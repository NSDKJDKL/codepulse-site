React

Первое приложение, компоненты и счётчик

Содержание

Что такое React?

React помогает собирать интерфейс из компонентов. Например, карточка курса может быть одним компонентом: вы передаёте ей название и ссылку, а React показывает её на странице.

Основные преимущества React:

  • Компонентный подход — приложение состоит из независимых, переиспользуемых компонентов
  • Обновление интерфейса — React применяет необходимые изменения к DOM после рендера
  • Однонаправленный поток данных — упрощает отладку
  • JSX — синтаксис, позволяющий писать HTML-подобный код в JavaScript
  • Большое сообщество — множество библиотек и готовых решений

Установка React

Создание нового React-приложения

Для учебного проекта используйте Vite с шаблоном React. Он создаст минимальное приложение, в котором можно сразу менять компоненты.

npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

Объяснение:

  • npm create vite@latest my-app -- --template react создаёт проект в папке my-app.
  • cd my-app открывает папку проекта в терминале.
  • npm install устанавливает зависимости проекта.
  • npm run dev запускает сервер разработки. Откройте адрес из терминала.

Требования к системе

Для работы с React вам понадобится:

  • Node.js свежей LTS-версии. Минимальные версии указаны в документации Vite.
  • npm устанавливается вместе с Node.js.
  • Текстовый редактор (рекомендуется VS Code)

Компоненты React

Компоненты — это строительные блоки любого React-приложения. Компонент принимает входные данные (props) и возвращает React-элементы, описывающие, что должно появиться на экране.

Функциональные компоненты

Простые JavaScript-функции, которые возвращают JSX

Классовые компоненты

ES6 классы, расширяющие React.Component

Функциональный компонент:

function Welcome(props) {
  return <h1>Привет, {props.name}!</h1>;
}

// Использование
<Welcome name="Виталий" />

Классовый компонент:

class Welcome extends React.Component {
  render() {
    return <h1>Привет, {this.props.name}!</h1>;
  }
}

// Использование
<Welcome name="Виталий" />

State и Props

Props (свойства)

Props — это данные, которые передаются от родительского компонента к дочернему. Props доступны только для чтения и не могут быть изменены дочерним компонентом.

State (состояние)

State — это внутренние данные компонента, которые могут изменяться. Когда state изменяется, компонент перерисовывается.

Пример использования State:

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Вы нажали {count} раз</p>
      <button onClick={() => setCount(count + 1)}>
        Нажми меня
      </button>
    </div>
  );
}

React Hooks

Хуки — это функции, которые позволяют «подцепиться» к возможностям React (таким как состояние и жизненный цикл) из функциональных компонентов. Хуки не работают внутри классов — они дают вам возможность использовать React без классов.

Хук Описание
useState Позволяет добавить state в функциональный компонент
useEffect Выполняет побочные эффекты в функциональных компонентах
useContext Позволяет подписаться на React context без вложенности
useRef Возвращает изменяемый ref-объект
useMemo Мемоизирует вычисленное значение
useCallback Мемоизирует функцию обратного вызова

Пример использования useEffect:

import { useState, useEffect } from 'react';

function Example() {
  const [count, setCount] = useState(0);

  // Аналогично componentDidMount и componentDidUpdate:
  useEffect(() => {
    document.title = `Вы нажали ${count} раз`;
  }, [count]); // Выполняется только при изменении count

  return (
    <div>
      <p>Вы нажали {count} раз</p>
      <button onClick={() => setCount(count + 1)}>
        Нажми меня
      </button>
    </div>
  );
}

JSX - JavaScript XML

JSX — это расширение синтаксиса JavaScript, которое позволяет писать HTML-подобный код внутри JavaScript. JSX делает код более читаемым и понятным, особенно при создании сложных пользовательских интерфейсов.

Важно знать:

  • JSX не является обязательным, но значительно упрощает разработку
  • JSX компилируется в обычные вызовы функций JavaScript
  • В JSX можно использовать любые JavaScript-выражения внутри фигурных скобок {}
  • React отображает подставленные строки как текст. Для обычных данных не нужно вставлять HTML вручную.

Пример JSX:

const name = 'Виталий';
const element = <h1>Привет, {name}!</h1>;

// JSX с выражениями
function formatName(user) {
  return user.firstName + ' ' + user.lastName;
}

const user = {
  firstName: 'Виталий',
  lastName: 'Вихарев'
};

const greeting = (
  <h1>
    Привет, {formatName(user)}!
  </h1>
);

Условный рендеринг

В React вы можете создавать отдельные компоненты, которые инкапсулируют нужное вам поведение. Затем вы можете рендерить только некоторые из них в зависимости от состояния вашего приложения.

Использование if/else:

function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <h1>С возвращением!</h1>;
  }
  return <h1>Пожалуйста, войдите.</h1>;
}

Использование тернарного оператора:

function LoginButton({ isLoggedIn }) {
  return (
    <button>
      {isLoggedIn ? 'Выйти' : 'Войти'}
    </button>
  );
}

Списки и ключи

В React вы можете создавать коллекции элементов и включать их в JSX, используя фигурные скобки {}. Для рендеринга списков обычно используется метод массива map().

Рендеринг списка:

function NumberList({ numbers }) {
  const listItems = numbers.map((number) =>
    <li key={number.toString()}>
      {number}
    </li>
  );

  return <ul>{listItems}</ul>;
}

// Использование
const numbers = [1, 2, 3, 4, 5];
<NumberList numbers={numbers} />

Важность ключей (keys):

  • Ключи помогают React определить, какие элементы изменились, добавились или удалились
  • Ключи должны быть уникальными среди соседних элементов
  • Лучше всего использовать строку, которая уникально идентифицирует элемент (например, ID из базы данных)

Практика

Создайте своё первое React-приложение:

  1. Создайте и запустите проект по инструкции из раздела «Установка React».
  2. Откройте файл src/App.jsx в редакторе.
  3. Замените заголовок стартовой страницы на «Мой первый курс» и сохраните файл. Проверьте изменение в браузере.

Следующий шаг

Добавьте компонент Counter из раздела «State и Props» и выведите <Counter /> в App. После трёх нажатий счётчик должен показать 3.
