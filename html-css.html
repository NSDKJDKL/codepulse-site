Что такое HTML и CSS?

HTML (HyperText Markup Language)

HTML — это язык гипертекстовой разметки, который используется для создания структуры веб-страницы. Он определяет, какие элементы будут отображаться на странице: текст, изображения, таблицы, видео и другие медиа-элементы.

CSS (Cascading Style Sheets)

CSS — это каскадные таблицы стилей, которые используются для оформления и визуального представления веб-страницы. С помощью CSS вы можете контролировать цвета, шрифты, расположение элементов и другие визуальные аспекты.

Основные элементы HTML

Элементы

Элементы указывают, как определять структуру и содержимое объектов на странице. Некоторые из часто используемых элементов включают в себя несколько уровней заголовков (определены как элементы с h1 до h6) и абзацев (определены как p); в список можно включить элементы a, div, span, strong и em и многие другие.

Теги

Теги — это элементы в угловых скобках, которые окружают содержимое. Например: <h1> и </h1>. Теги наиболее часто встречаются в парах открывающих и закрывающих тегов. Открывающий тег отмечает начало элемента. Он состоит из символа <, затем идёт имя элемента и завершается символом >.

Атрибуты

Атрибуты являются свойствами, применяемыми для предоставления дополнительной информации об элементе. Наиболее распространённые атрибуты включают в себя атрибут id, который идентифицирует элемент; атрибут class, который классифицирует элемент; атрибут src, который определяет источник встраиваемого содержимого; и атрибут href, который указывает ссылку на связанный ресурс.

Самозакрывающиеся элементы

Элементы, которые не требуют закрывающего тега: <br>, <hr>, <img>, <input> и другие.

Пример HTML документа

<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="utf-8">
    <title>Привет, мир!</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый сайт.</p>
  </body>
</html>

Объяснение:

  • <!DOCTYPE html> — объявление типа документа
  • <html> — корневой элемент HTML-документа
  • <head> — содержит метаданные документа
  • <meta charset="utf-8"> — определяет кодировку документа
  • <title> — заголовок страницы, отображаемый во вкладке браузера
  • <body> — видимое содержимое страницы

Основные понятия CSS

Селекторы

Определяют, к какому элементу применить стили

Свойства

Определяют, какие стили применить

Значения

Определяют конкретные параметры стилей

p {
  color: #333;
  font-size: 16px;
  margin: 10px 0;
}

.header {
  background-color: #f8f9fa;
  padding: 20px;
  text-align: center;
}

#main-content {
  max-width: 800px;
  margin: 0 auto;
}

Типы селекторов CSS

Тип селектора Пример Описание
Селектор элемента h1 Выбирает все элементы указанного типа
Селектор класса .my-class Выбирает элементы с определённым значением атрибута class
Селектор ID #my-id Выбирает элемент с определённым значением атрибута id
Универсальный селектор * Выбирает все элементы

Практика

Попробуйте создать простую веб-страницу:

  1. Создайте папку с именем "my-first-site" на вашем компьютере
  2. Создайте файл index.html в этой папке
  3. Скопируйте в него пример HTML-документа.
  4. Откройте файл в веб-браузере
  5. Добавьте правило h1 { color: navy; } в <style> внутри <head>. Сохраните файл и обновите страницу: заголовок станет тёмно-синим.
